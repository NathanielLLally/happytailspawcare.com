== Description ==

🚀 **MarqueeX** is the most powerful and SEO-optimized WordPress marquee plugin engineered specifically for **Gutenberg blocks and Elementor page builders**. Transform your website with stunning **horizontal and vertical scrolling content, dynamic news tickers, professional announcement banners, infinite content sliders, and smooth marquee animations** using our comprehensive collection of native Elementor widgets and intuitive Gutenberg blocks.

Whether you're building **news websites, eCommerce stores, business portfolios, or marketing landing pages**, MarqueeX delivers professional-grade scrolling solutions that enhance user engagement while maintaining perfect **SEO performance and Core Web Vitals optimization**. Create eye-catching **testimonial sliders, client logo carousels, product showcases, breaking news feeds, promotional banners, and dynamic content galleries** without any coding knowledge required.

Our plugin features **native Elementor integration with Image Marquee, Text Marquee, and News Ticker widgets**, plus a powerful **Gutenberg MarqueeX block** that works seamlessly with all WordPress themes and Full Site Editing (FSE) environments. Every marquee element is built with **accessibility standards (WCAG compliant), mobile-responsive design, and search engine optimization** to ensure your scrolling content performs exceptionally across all devices and search rankings.

### Quick Start Guide ###

= For Elementor Users: =
*1. Install & Activate MarqueeX
2. Edit any page with Elementor
3. Make sure turn on the Elementor in MarqueeX Dashboard
4. Find MarqueeX widgets in the elements panel
5. Drag Image Marquee, Text Marquee, or News Ticker widgets
6. Customize settings and add content
7. Preview & Publish!*

= For Gutenberg Users: =

*1. Install & Activate MarqueeX
2. Edit any page/post with Gutenberg
3. Make sure turn on the Gutenberg in MarqueeX Dashboard
4. Add MarqueeX block from block inserter
5. Configure animation and design settings
6. Add your content and publish!*

== Installation ==

1. Go to Plugins > Add New
2. Search for "MarqueeX"
3. Click "Install Now" then "Activate"
4. Select with page builder you are using in MarqueeX Dashboard
5. **For Elementor:** Find MarqueeX widgets in Elementor editor
6. **For Gutenberg:** Add MarqueeX block to any page/post
7. Customize settings and add your content

== Frequently Asked Questions ==

= Does MarqueeX work with Elementor? =
Yes! MarqueeX includes native Elementor widgets: Image Marquee, Text Marquee, and News Ticker widgets with full visual editor integration.

= Is it compatible with Gutenberg blocks? =
Absolutely! MarqueeX provides a native Gutenberg block that works seamlessly with all WordPress blocks and Full Site Editing themes.

= Will it work with my theme and page builder? =
Yes! MarqueeX is designed for maximum compatibility with any WordPress theme supporting Gutenberg or Elementor page builders.

= Can I use both Elementor widgets and Gutenberg blocks? =
Definitely! You can use MarqueeX Elementor widgets on Elementor pages and Gutenberg blocks on regular WordPress pages or posts.

= How do I create a horizontal marquee in Elementor? =
Simply drag the Image Marquee or Text Marquee widget to your Elementor page, configure the direction settings, and add your content.

= Are the animations SEO-friendly? =
Yes! All MarqueeX animations use SEO-optimized HTML markup and CSS3 animations that don't impact search engine crawling.

= Can I control animation speed and direction? =
Full control over scroll speed, direction (left, right, up, down), timing, and easing effects in both Elementor and Gutenberg.

= What content can I display in marquees? =
Any content! Text, images, videos, buttons, custom HTML, and even other Gutenberg blocks or Elementor elements.
